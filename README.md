# Tip Splitter Calculator 

A beginner-friendly Python app that calculates how much each person should pay when splitting a bill — including a customizable tip percentage.

## 💡 Features

- Takes total bill amount as input  
- Lets user select tip percentage (10%, 12%, 15%)  
- Splits the final amount evenly among chosen number of people  
- Rounds the result to 2 decimal places for accuracy

## 🧪 Sample Output
Welcome to the tip calculator!
What was the total bill? $120
What percentage tip would you like to give? 15
How many people to split the bill? 3
Each person should pay: $46.0
